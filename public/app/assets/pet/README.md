# Ассеты питомца

`pet-symbiote-calm.png` и `pet-symbiote-angry.png` — спокойная и злая формы
нового питомца «Симбиот». Его злая форма включается автоматически при
настроении «злое».

Сюда можно положить кастомные изображения/спрайты/анимации питомца
(например, PNG/SVG для разных состояний: happy, neutral, worried, sad),
если не хотите использовать эмодзи по умолчанию.

Затем подключите их в `frontend/js/pet.js`, заменив `PET_EMOJIS` на пути
к файлам и обновив рендер в `renderPetState()`.
