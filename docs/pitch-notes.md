# Заметки для питч-дека (до 12 слайдов)

Структура, которую можно использовать под требования брифа EcoFin:

1. **Титул** — название проекта, трек, команда
2. **Проблема** — семьи/школы/бизнес не видят, куда уходят ресурсы и деньги;
   существующие решения либо слишком сложны, либо дают общие советы
3. **Решение** — ЭкоДвойник: AI-платформа + живой питомец-ассистент,
   который переводит данные потребления в понятные советы и деньги
4. **Как это работает** — схема: датчики/ручной ввод → анализ → питомец → экономия
5. **Демо (скриншоты/видео)** — дашборд + чат с питомцем + реакция на аномалию
6. **Технология** — датчики/умные счётчики, ручной ввод, фото счётчиков и квитанций
   (распознавание через Claude Vision), Node.js backend, AI-рекомендации (LLM)
7. **Почему питомец, а не дашборд** — эмоциональная вовлечённость, персонализация,
   решает проблему "общих советов без контекста" из брифа
8. **Целевая аудитория** — домохозяйства, школы, малый бизнес Казахстана
9. **Экономический эффект** — расчёт потенциальной экономии в тенге/мес
10. **Бизнес-модель / масштабирование** (если требуется) — freemium, B2G со школами,
    партнёрство с энергосбытами
11. **Roadmap** — реальные IoT-интеграции, мобильное приложение, соревнования
    между дворами/школами
12. **Команда + контакты**

## Ключевые цифры для питча (замените на реальные после теста)

- Средняя экономия воды: ~X% за счёт своевременного обнаружения утечек
- Средняя экономия на счетах: ~X ₸/месяц на семью
- Время окупаемости базового датчика: ~X месяцев

## "Вау-момент" для демо-видео

1. Показать реальный (или синтетический) рост потребления воды
2. Питомец "грустнеет" и присылает сообщение о вероятной утечке
3. Пользователь получает конкретную рекомендацию с расчётом экономии
4. (Опционально) Живая демонстрация подключенного датчика (CT-клещи на удлинителе)
