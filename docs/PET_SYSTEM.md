# 🤖 Документация по системе питомца-ассистента

## Обзор

Питомец EcoTwin — это интеллектуальный цифровой ассистент, который "живёт" в приложении и реагирует на поведение пользователя. Система состоит из нескольких компонентов:

1. **aiService.js** — основной сервис с ответами питомца
2. **petStateService.js** — определение настроения питомца на основе данных
3. **petEmotions.js** — библиотека эмоциональных реакций
4. **petIntelligence.js** — интеллектуальная система анализа сообщений

## Архитектура

```
User Message
    ↓
[analyzeMessageContext] → Определяем тип сообщения
    ↓
[computePetState] → Вычисляем настроение питомца
    ↓
[llmReply или ruleBasedReply] → Выбираем ответ
    ↓
[selectBestResponse] → Подбираем наиболее уместный вариант
    ↓
Response
```

## Настроения питомца (Pet Mood)

### 😊 Happy (Счастливый)
- **Условие**: Экономия ≥ 10% от нормы (тренд ≤ -10%)
- **Поведение**: Питомец растёт и развивается, даёт позитивные ответы
- **Пример**: "Я расту! Спасибо, что бережёшь ресурсы."

### 😐 Neutral (Нейтральный)
- **Условие**: Расход в пределах нормы, без аномалий
- **Поведение**: Питомец стабилен, даёт информативные ответы
- **Пример**: "Вот что у нас происходит на этой неделе:"

### 😟 Worried (Обеспокоенный)
- **Условие**: Расход выше нормы (тренд +10% до +25%)
- **Поведение**: Питомец обеспокоен, рекомендует проверить оборудование
- **Пример**: "Есть на что обратить внимание:"

### 😢 Sad (Грустный)
- **Условие**: Обнаружены аномалии или очень высокий расход (тренд > 25%)
- **Поведение**: Питомец грустит, просит помощь
- **Пример**: "Мне тяжеловато сейчас — расход сильно вырос"

## Компоненты системы

### 1. aiService.js - Основной сервис

#### Основные функции:

```javascript
// Случайный выбор из массива
pick(arr) → string

// Основной рабочий конь — rule-based ответы
ruleBasedReply(summary, petState, userMessage, user) → string

// Рекомендации для пользователя
ruleBasedRecommendations(summary) → array

// Интеграция с AI API (Claude)
llmReply(summary, petState, userMessage, user) → promise<string>
```

#### Типы вопросов, которые питомец понимает:

| Тип | Примеры | Ответ |
|-----|---------|-------|
| Приветствие | "привет", "хэй" | Счастливое приветствие + сводка |
| "Как дела?" | "как дела", "как ты" | Ответ в зависимости от настроения |
| Про воду | "как дела с водой" | Специфичные советы по воде |
| Про свет | "расход электричества" | Специфичные советы по электричеству |
| Почему? | "почему расход вырос" | Объяснение через аномалии |
| Совет | "дай совет", "рекомендацию" | Рекомендации на основе тренда |
| Спасибо | "спасибо", "спс" | Благодарные ответы |
| Default | Все остальное | Общая сводка + мотивация |

### 2. petStateService.js - Состояние питомца

```javascript
computePetState(summary) → {
  mood: 'happy' | 'neutral' | 'worried' | 'sad',
  level: 1-10,  // Уровень питомца (1=минимум, 10=максимум)
  worstTrend: number  // Наихудший тренд (воды или электричества)
}
```

**Формула уровня питомца:**
```
level = 5 - (avgVsBenchmarkPercent / 20)
level = min(1, max(10, level))
```

### 3. petEmotions.js - Библиотека эмоций

Содержит готовые фразы для реакции на разные уровни потребления:

```javascript
petEmotions = {
  waterConsumption: {
    veryLow, low, normal, high, veryHigh
  },
  electricityConsumption: {
    veryLow, low, normal, high, veryHigh
  },
  trend: {
    excellent, good, stable, concerning, warning
  },
  mood: {
    ecstatic, happy, content, worried, sad
  },
  congratulations: [...],
  motivationalPhrases: [...]
}
```

### 4. petIntelligence.js - Интеллектуальная система

#### Анализ сообщения:
```javascript
analyzeMessageContext(userMessage) → {
  isGreeting: boolean,
  isQuestion: boolean,
  isPositive: boolean,
  isNegative: boolean,
  isRequest: boolean,
  isEmotional: boolean,
  hasEmoji: boolean
}
```

#### Система оценки:
```javascript
scoreMessageRelevance(context, moodType) → number
// Позитивное сообщение + счастливый питомец = +10
// Отрицательное сообщение + грустный питомец = +8
// Вопрос = +5
// Запрос помощи = +7
// Эмоциональное сообщение = +6
```

#### Персонализация:
```javascript
generatePersonalizedResponse(summary, petState, messageHistory) → {
  focus: ['water' | 'electricity' | 'money'],
  shouldMention: 'trends' | 'overview',
  tone: mood
}
```

## Интеграция с AI (Claude)

Если задан `ANTHROPIC_API_KEY`, питомец использует реальный AI для более естественных ответов:

```javascript
async llmReply(summary, petState, userMessage, user) {
  // Отправляет запрос к Claude API
  // Использует system prompt с описанием питомца и текущими данными
  // Возвращает естественный ответ вместо rule-based
}
```

**System prompt для Claude:**
```
Ты — дружелюбный цифровой питомец-ассистент приложения ЭкоДвойник.
Ты живёшь у пользователя и "чувствуешь" на себе его потребление ресурсов.
Отвечай коротко (2-4 предложения), тепло и с характером.
Твоё текущее настроение: [mood]
Данные пользователя: [summary]
```

## Как добавить новые ответы

1. **Добавить в GREETING_INTROS**, если это приветствие:
```javascript
const GREETING_INTROS = [
  'Привет! Рад тебя видеть.',
  'Ваш новый вариант тут',  // ← Добавить
];
```

2. **Добавить в HOW_ARE_YOU_REPLIES**, если это реакция на "Как дела?":
```javascript
const HOW_ARE_YOU_REPLIES = {
  happy: [
    '...',
    'Ваш новый вариант тут',  // ← Добавить
  ],
  // ... другие настроения
};
```

3. **Добавить условие в ruleBasedReply()**, если это специальный тип вопроса:
```javascript
if (msg.includes('ваше ключевое слово')) {
  return 'Ваш специальный ответ';
}
```

## Производительность

- **Без API ключа**: Все ответы используют rule-based систему (мгновенно)
- **С API ключом**: Ответы идут через Claude API (200-500мс)
- **Fallback**: Если API недоступен, автоматически переходит на rule-based

## Тренды

Каждый компонент отслеживается отдельно:
- **Тренд < -10%**: Экономия (happy)
- **Тренд от -10% до +10%**: Стабильно (neutral)
- **Тренд от +10% до +25%**: Повышение (worried)
- **Тренд > +25%**: Критичное повышение (sad)
