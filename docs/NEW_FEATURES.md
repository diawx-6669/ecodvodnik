# Новые функции в ЭкоДвойник

## 1. Цели потребления (Consumption Goals)

Позволяет пользователям устанавливать месячные лимиты на потребление воды и электричества.

### API Endpoints

- **POST /api/goals** - Установить/обновить цель
  ```json
  {
    "type": "water|electricity",
    "targetValue": 5000,
    "monthYear": "2026-08"
  }
  ```

- **GET /api/goals?monthYear=2026-08** - Получить цели

- **GET /api/goals/progress?monthYear=2026-08** - Получить прогресс с % использования

### UI Компоненты

- Виджет прогресса с визуальной полосой
- Индикатор: зелёный (в норме) / красный (превышено)
- Отображение процента использованного лимита

## 2. Система уведомлений (Alerts)

Автоматические уведомления о превышении установленных норм.

### API Endpoints

- **POST /api/alerts/check** - Проверить и создать уведомления
- **GET /api/alerts** - Получить неподтвержденные уведомления
- **PUT /api/alerts/:alertId/acknowledge** - Отметить как прочитанное

### Особенности

- Автоматическое создание при превышении норм
- Указание % превышения
- Возможность отметить как прочитанное
- Периодическая проверка каждые 5 минут

## 3. Экспорт данных (Data Export)

Позволяет скачивать собственные данные о потреблении в CSV.

### API Endpoints

- **GET /api/export/csv** - Скачать CSV с фильтрами:
  - `startDate` (опционально)
  - `endDate` (опционально)
  - `type` (опционально: water/electricity)

- **GET /api/export/summary** - Получить статистику
  - Итоги по воде и электричеству
  - Среднее значение на одно измерение
  - Количество измерений

### Формат CSV

Включает столбцы:
- Дата и время
- Тип ресурса
- Значение
- Единица измерения
- Источник (Arduino/CSV/Ручной ввод)

## 4. Утилиты расчётов (Consumption Utils)

Встроенные функции для анализа потребления:

```javascript
// Расчет стоимости
calculateCost(1000, 'water') // 50,000 тенге (по умолчанию)

// Прогноз на конец месяца
forecastMonthlyUsage(5000, 15) // Прогноз за 30 дней

// Категоризация (низкое/среднее/высокое)
categorizeUsage(5000, 6000) // { level: 'среднее', color: '#eab308' }

// Рекомендуемые нормы
getRecommendedUsage('household', 4) // Нормы для семьи из 4 человек
```

## 5. Расширенная аналитика (Advanced Analytics)

Глубокий анализ паттернов потребления:

- **Обнаружение аномалий** - выявление необычных скачков потребления (z-score анализ)
- **Пиковые часы** - определение времени максимального потребления
- **Сравнение периодов** - анализ тренда между месяцами
- **Потенциальная экономия** - расчет сумм на сэкономить в тенге
- **AI рекомендации** - интеграция с питомцем для персональных советов

## Интеграция

Все новые функции полностью интегрированы с существующей системой:

- Используют JWT аутентификацию
- Работают с текущей БД (JSON файл)
- Совместимы с Arduino датчиками
- Сохраняют данные по пользователям

## Примеры использования

### Установить месячную цель на 5000 л воды

```javascript
await goalsAPI.setConsumptionGoal('water', 5000, '2026-08');
```

### Загрузить прогресс

```javascript
const progress = await goalsAPI.getGoalProgress('2026-08');
// Returns: [{ type, targetValue, currentUsage, percentageUsed, isExceeded, ... }]
```

### Экспортировать данные

```javascript
const blob = await goalsAPI.exportConsumptionDataAsCSV('2026-01-01', '2026-08-31');
// Автоматически скачивается CSV файл
```

### Анализировать аномалии

```javascript
const anomalies = analyzeConsumptionAnomaly(readings, 'water');
// Returns: [{ timestamp, value, deviation, severity }]
```

## Примечания

- Все новые функции требуют аутентификации
- Данные пользователей приватны и не видны другим пользователям
- Целевые показатели сохраняются в БД для исторического анализа
- Уведомления автоматически проверяются каждые 5 минут
