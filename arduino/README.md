# Arduino Uno прошивки

Две прошивки для сбора реальных данных о потреблении ресурсов.

 **Arduino Uno не имеет Wi-Fi**, поэтому схема работы такая:

```
[Arduino Uno] --USB Serial--> [Компьютер: serial_bridge.py] --HTTP POST--> [Backend]
```

Плата печатает показания в Serial-порт в виде JSON-строк, а Python-скрипт
`scripts/serial_bridge.py`, запущенный на компьютере (к которому Uno
подключена по USB), читает эти строки и пересылает их на backend.

## potentiometer_demo/ (простой вариант — нет спецдатчиков)

Если у вас нет геркона или SCT-013 (это специфичные детали, которых может
не быть в обычном стартовом наборе) — используйте эту прошивку. Она
работает на **обычных потенциометрах**, которые есть почти в каждом
наборе Arduino Uno. Подробности и схема подключения — в
`potentiometer_demo/README.md`. Формат данных полностью совместим с
остальной системой — менять backend/serial_bridge.py не нужно.

## water_sensor/

Считает импульсы с геркона/импульсного датчика на счётчике воды.
Каждый импульс = определённый объём воды (зависит от модели счётчика,
обычно указано на корпусе, например "1 импульс = 1 литр").

**Компоненты:**
- Arduino Uno
- Геркон-датчик или готовый импульсный выход счётчика
- Провод к пину **2** (обязательно пин с поддержкой прерываний — на Uno это 2 или 3)

## electricity_sensor/

Измеряет ток через токовые клещи (CT-clamp, например SCT-013-030) и
считает потреблённую мощность/энергию.

**Компоненты:**
- Arduino Uno
- Датчик тока SCT-013 (неинвазивный, надевается на провод без разрезания)
- Резистор нагрузки (burden resistor, обычно идёт в комплекте или ~33 Ом)
- Подключение к пину **A0**

## Как запустить всю связку

1. Откройте `.ino` файл в Arduino IDE, выберите плату **Arduino Uno** и
   нужный COM-порт, загрузите прошивку на плату.
2. Откройте Serial Monitor (9600 бод) и убедитесь, что плата печатает
   JSON-строки вида `{"type":"water","value":1.0}`.
3. Установите зависимости для моста:
   ```bash
   cd scripts
   pip install -r requirements.txt
   ```
4. Запустите мост, указав свой порт:
   ```bash
   python3 serial_bridge.py --port COM3
   # или на Linux/macOS, например:
   python3 serial_bridge.py --port /dev/ttyUSB0
   ```
   Порт можно посмотреть в Arduino IDE: **Инструменты → Порт**.
5. Убедитесь, что backend запущен (`npm run dev` в папке `backend/`) —
   мост шлёт данные на `http://localhost:3000/api/readings` по умолчанию.
   Если backend на другом компьютере/порту — укажите `--server`.

 Если реального железа нет под рукой — используйте
`scripts/generate_sample_data.py` для генерации демо-данных, платформа
будет работать точно так же.

## Важно про DEVICE_TOKEN

Backend проверяет токен устройства для запросов с `source: "arduino"`
(см. `backend/.env` → `DEVICE_TOKEN`). По умолчанию используется
`change_me_please` — при желании поменяйте его в `backend/.env` и
передайте тот же токен мосту через `--token`.
