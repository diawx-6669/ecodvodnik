# Упрощённая демо-прошивка на потенциометрах

Для тех, у кого нет геркона/SCT-013 из "боевых" прошивок — подойдёт
самый обычный потенциометр из стартового набора Arduino Uno.

## Что нужно
- Arduino Uno
- 1–2 потенциометра (любые, например на 10 кОм — стандартные из набора)
- Breadboard + 3 провода "папа-папа" на каждый потенциометр

## Подключение (на каждый потенциометр)
```
Крайний вывод 1 -> 5V
Крайний вывод 2 -> GND
Средний вывод (движок) -> аналоговый пин Arduino
```
- Потенциометр "вода" -> пин **A0**
- Потенциометр "электричество" -> пин **A1** (если он у вас есть)

Если потенциометр только один — используйте его как A0 ("вода"), а блок
электричества в коде закомментируйте (см. комментарий в .ino файле).

## Как запустить
1. Откройте `potentiometer_demo.ino` в Arduino IDE, выберите плату
   **Arduino Uno** и свой COM-порт, загрузите прошивку.
2. Откройте Serial Monitor (9600 бод) — покрутите ручку(и), должны
   появляться строки вида `{"type":"water","value":3.2}`.
3. Дальше — как в основном `arduino/README.md`: запускаете
   `scripts/serial_bridge.py --port <ваш порт>`, а backend уже принимает
   данные точно так же, как от "настоящих" датчиков — менять ничего не
   нужно.
