# Project Summary - August 20, 2026

## Добавлено: система целей потребления, уведомлений и экспорта данных

Комплексное расширение функциональности для управления потреблением ресурсов.

### Системы целей (Goals):
- `backend/models/Goal.js` — модель целей потребления на месяц
- `backend/controllers/goalsController.js` — API для установки и отслеживания целей
- `backend/routes/goals.js` — маршруты /api/goals
- **Функциональность**: установка лимитов на воду/электричество, расчет прогресса с процентами, выявление превышений

### Система уведомлений (Alerts):
- `backend/models/Alert.js` — модель для уведомлений о превышениях
- `backend/controllers/alertsController.js` — API для создания и управления уведомлениями
- `backend/routes/alerts.js` — маршруты /api/alerts
- **Функциональность**: автоматические уведомления при превышении норм, отметка как прочитанные

### Экспорт данных (Export):
- `backend/controllers/exportController.js` — контроллер для экспорта
- `backend/routes/export.js` — маршруты /api/export
- **Функциональность**: экспорт в CSV с фильтрацией по датам и типу, сводка потребления

### Frontend компоненты:
- `frontend/js/goals-api.js` — API клиент для целей, уведомлений, экспорта
- `frontend/js/goals-ui.js` — UI компоненты и логика отображения
- `frontend/css/goals.css` — стили для целей, уведомлений и экспорта (365 строк)
- **Особенности**: визуальные прогресс-бары, периодическая проверка уведомлений, скачивание CSV

### Утилиты и аналитика:
- `frontend/js/consumption-utils.js` — функции расчета стоимости, прогнозирования, категоризации
- `frontend/js/analytics-advanced.js` — анализ аномалий, пиковых часов, сравнение периодов
- **Функциональность**: z-score анализ, рекомендации по сэкономии, AI интеграция

### Тестирование:
- `backend/tests/goals.test.js` — 11 тестов для целей, уведомлений и экспорта (278 строк)

## Добавлено: тесты backend + CI

- `backend/tests/` — 20 автотестов на Jest + Supertest: health-check,
  регистрация/вход/`/me` (валидация email, длины пароля, дубликатов
  email, невалидного токена), приём и чтение показаний (валидация типа,
  отрицательных и аномально больших значений, проверка device token
  Arduino), а также приватность данных между гостем/аккаунтами и между
  разными аккаунтами.
- `backend/server.js` теперь экспортирует `app` отдельно от `listen()`,
  чтобы тесты могли поднимать сервер без реального порта.
- `.github/workflows/backend-tests.yml` — тесты гоняются автоматически
  на каждый push/PR в `main`.
- Исправлено: `package-lock.json` был в `.gitignore`, из-за чего `npm ci`
  в CI не смог бы найти lock-файл — теперь он коммитится.
