# Гайд по внесению вклада в EcoTwin

Спасибо за интерес к нашему проекту!

## Как начать разработку

### Предварительные требования
- Node.js 18+
- npm или yarn
- Git

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/ecodvoinik.git
cd ecodvoinik

# Установите зависимости backend
cd backend
npm install
cd ..

# Копируйте пример конфигурации
cp .env.example backend/.env
```

### Запуск проекта

```bash
# Backend (из директории ecodvodnik)
cd backend
npm run dev

# Frontend (в новом терминале)
# Просто откройте frontend/index.html в браузере
```

## Процесс разработки

1. **Создайте фичу-бранч**: `git checkout -b feature/my-feature`
2. **Пишите код** с соблюдением EditorConfig
3. **Тестируйте** изменения локально
4. **Коммитьте** с понятными сообщениями: `git commit -m "feat: добавлена новая функция"`
5. **Пушьте**: `git push origin feature/my-feature`
6. **Откройте Pull Request**

## Соглашения о коде

- Используйте **2 пробела** для отступов в JS/JSON
- Максимальная длина строки: **100 символов**
- Переменные: camelCase
- Классы: PascalCase
- Константы: UPPER_SNAKE_CASE

## Структура коммитов

Используйте conventional commits:
- `feat:` — новая функция
- `fix:` — исправление ошибки
- `docs:` — изменения в документации
- `refactor:` — рефакторинг без изменения функциональности
- `test:` — добавление/изменение тестов
- `chore:` — обновление зависимостей, конфигурации

Пример: `feat: добавлена система уведомлений для пользователя`
